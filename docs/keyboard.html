Show keys for

Navigation

↑ ↓ ← →Move the cursor
⇧arrowsExtend the selection
⌘arrowsJump to the edge of the content run (Excel-style)
⌘⇧arrowsExtend the selection by content jumps
Tab / ⇧TabMove right / left
⌘ASelect the used range
⌘G or ⌘JGo to cell / range
Alt→ / Alt←Next / previous sheet (also Alt↑ / Alt↓)

Editing

EnterEdit the cell (opens the code editor on code cells)
any characterStart typing into the cell
=On an empty cell: start a formula in the code editor
/On an empty cell: choose a cell type (Python, JavaScript, Formula); on a code cell: open its editor
Backspace / DeleteClear the selected cells
⌘ZUndo
⌘⇧Z or CtrlYRedo
⌘D / ⌘RFill down / fill right (series-aware)
⌘; / ⌘⇧;Insert today's date / date + time

Inline cell input

EnterCommit and move down
Tab / ⇧TabCommit and move right / left
↑ / ↓Commit and move up / down
EscCancel the edit

Clipboard & export

⌘C / ⌘X / ⌘VCopy / cut / paste (TSV, works with other apps)
⌘⇧CCopy the selection as a PNG image
⌘⇧EDownload the selection as CSV

Formatting

⌘BBold
⌘IItalic
⌘⌥CCopy the selection's formats (borders included)
⌘⌥VPaint the copied formats over the selection (tiles)
⌘\Clear formatting

View & zoom

⌘+ / ⌘−Zoom in / out
⌘0Zoom to 100%
⌘8Zoom to the selection
⌘9Zoom to fit the used range
⌘.Presentation mode (Esc leaves it)
Space + dragPan the grid

Find

⌘FFind in the current sheet
⌘⇧FFind across all sheets
Enter / ⇧EnterNext / previous match
EscClose the search bar

Menus & panels

⌘P or ⌘K or ⌘/Command palette (↑↓ select, Enter run)
⌘OFiles page — your stored files and the examples gallery
EscClose the open dialog, menu, or panel

Code editor

⌘EnterRun the cell
⌘⇧EnterRerun all code cells (works anywhere)
TabIndent (4 spaces)
click / drag gridFormula mode: insert the cell or range reference; pointing elsewhere replaces it until you type
EscClose the editor

Formula autocomplete

↑ / ↓Choose a function (signature and docs preview follow)
Tab or EnterInsert it — the first argument placeholder is selected for type-over
EscDismiss the list (the editor stays open)

Note: the grid uses 0-based coordinates — column A is 0 and row 0 exists. Cursor and selection are always shown in the bottom-left status bar; clicking it opens Go to.
