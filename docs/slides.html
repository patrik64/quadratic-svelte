Quadratic Svelte

Porting the data-science spreadsheet — infinite WebGL grid, a Rust formula core, Python and JavaScript cells — from React to SvelteKit, then tracking the original as it moved on.

quadratic-svelte · August 2026 · 22 commits · main @ 3bfcc91

A2 · The brief

Same spreadsheet, new frame

Quadratic is an infinite grid where a cell can hold text, an Excel-style formula, or code — with results spilling back onto the sheet. The original is a React app. The task: rebuild it in SvelteKit with the same data model, interactions, and file format. Then a second brief: the upstream repo had moved from the v0.3 alpha this was based on to the v0.24 production monorepo — bring across what fits.

Infinite gridPan and zoom in all four directions; negative coordinates are first-class (column nA, row n5).
Formula cellsA1 references and ranges, evaluated by the quadratic-core Rust crate compiled to WASM.
Python cellsPyodide in the browser; the last expression becomes the value, DataFrames spill as ranges.
JavaScript cellsA first-class language upstream since v0.24 — the returned value lands on the grid.

A4 · Renderer

A WebGL grid that never redraws what it doesn't have to

Display objects persist between frames, so panning and zooming are pure viewport transforms. Layers redraw only via dirty flags, cell layers re-cull only when the visible range changes, and label rasterization is budgeted per frame.

15.7 s
single blocked frame on a 13,000-cell sheet — first draft, before range-gating and label budgeting
16.6 ms
average frame while panning the same sheet — steady 60 fps, worst frame 17.7 ms
10%–1000%
zoom range with pinch, ⌘+wheel, space-drag pan and inertia via pixi-viewport

A5 · Formulas

A6 · Code cells

Two languages, one dependency graph

Python runs on Pyodide (3.12) with numpy and pandas, loaded on first use. The API is the original's: cell(), getCells() → DataFrame, cells[…]; the last expression is the output.

total = cell(3, 6)
df = getCells((0, 2), (3, 5), first_row_header=True)
result = [total, total * 2]
result                       # spills down

JavaScript follows the modern client: the returned value becomes the output, 1-D arrays spill down, 2-D as rows, arrays of objects get a header row, and console.log is captured.

const n = q.cells('B3');
console.log('building', n, 'rows');
const rows = [['n', 'squared']];
for (let i = 1; i <= n; i++) rows.push([i, i * i]);
return rows;                // spills as a table

Every read is recorded, so editing an input re-runs whatever depends on it — the graph doesn't care which language a cell speaks. A formula can sum a table a JS cell produced from a value Python computed.

A8 · Tracking upstream

What came back from v0.24

The original had moved on by twenty-one minor versions. These are the parts that fit this port's architecture, taken deliberately rather than wholesale.

  • The formula function library — 63 functions, matched to the modern core's semantics function by function
  • JavaScript as a real cell language, with the modern q.cells() API and spill rules
  • Multi-sheet files and the SheetBar tab UX
  • The menubar layout, the grid context menu, and Copy as PNG / Download CSV / Rerun all code
  • Modern visuals: blue accent cursor #2463eb, slate gridlines that fade as you zoom out, amber JavaScript cells
  • = starts a formula directly; / opens the cell type menu

Skipped by choice: auth, multiplayer, and AI (out of scope), and the 1-based A1 overhaul — it would break file compatibility, though letter column headings are now the default look.

A9 · Closing the gap

Then the distance kept shrinking

After the first backport wave, the rest of the ledger was worked down feature by feature — each one browser-verified before its commit.

  • Cross-sheet references — Sheet1!A0, 'My Sheet'!A0:B2 — resolved at evaluation time, with a cross-sheet dependency graph so edits ripple between sheets
  • Formulas relocate: row/column inserts and deletes rewrite A1 references in formula text ($ pins respected) via new adjust_formula / relocate_formula Rust exports
  • IndexedDB autosave — localStorage's ~5 MB quota silently truncated large sheets; save failures now surface in the status bar
  • Find (⌘F, with an all-sheets mode), fill-handle drag and ⌘D/⌘R with series detection, and a live Sum·Avg·Count selection summary
  • Formula autocomplete at the caret, powered by the core's dormant Monaco LSP export — six array functions spilling onto the grid joined the registry the same week
  • Wrapped text with undoable row autofit, and cell borders with color and the full set of application modes

A11 · Honest ledger

Not ported (yet)

  • AI cells and SQL connection cells
  • Auth, sharing, and multiplayer
  • The format painter
  • The financial, engineering, and database function categories
  • The Electron desktop shell

Merged cells aren't on this list because the original doesn't have them either. The trade that shaped the rest: this port stays on the v1.3 file format and 0-based coordinates, so it can still open the original's files.

A12 · Run it

Two commands

npm install
npm run dev        # → http://localhost:5173

# only when the Rust or the examples change:
npm run build:wasm
npm run examples

The built wasm pkg/ is committed, so the app runs without a Rust toolchain. Docs live in README.md; this deck is docs/slides.html, and every keyboard shortcut is on docs/keyboard.html.
